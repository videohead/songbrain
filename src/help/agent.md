# The agent panel

The agent is an AI assistant that can read and edit your chart. Open it with the **network button** in the top bar. It is hidden by default and your conversation is kept when you hide it.

## What to ask

- "Transpose to Bb."
- "Insert a ii–V before measure 8."
- "Explain the selected bars."
- "Make the last four bars more bebop."
- "Analyze this progression."

Select bars in the grid first and the agent knows which ones you mean. It also knows where the playback cursor is.

## Changes are normal edits

Everything the agent does goes through the same undo history as your own edits, so **Ctrl+Z** takes it back.

## Settings

The **⚙** button in the panel lets this browser use its own server URL, API key and model. **Clear** starts a new conversation.
