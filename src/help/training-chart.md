# The training chart

A 32-bar chart built to exercise everything the trainer understands. One chord per bar, 4/4, key of C.

**Section A (bars 1–16), the verse.** Diatonic changes around a ii–V–I spine. It sets the style's basic feel. Export this with the style's **A** (verse) feel.

```
| Cmaj7 | Am7   | Dm7 | G7  |
| Cmaj7 | Am7   | Dm7 | G7  |
| Em7   | A7    | Dm7 | G7  |
| Cmaj7 | Cmaj7 | Cmaj7 | Cmaj7 |
```

**Section B (bars 17–32), the chorus.** Busier, with secondary dominants and colour chords. Export this with the style's **B** (chorus) feel.

```
| Fmaj7 | F#m7b5 | Em7 | A7   |
| Dm7   | G7     | Em7 | A7   |
| D7    | G7     | C7  | F7   |
| Fm7   | Bb7    | Cdim | Cmaj7 |
```

The chart covers all five chord classes the trainer tags hits with: major, minor, dominant, half-diminished (F#m7b5) and diminished (Cdim). That lets a fill or accent depend on the harmony.

The same chart is used for A and B. Export the whole 32 bars for each substyle; the trainer quantises to the bars that contain notes.
